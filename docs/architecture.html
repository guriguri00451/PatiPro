🔄 データフロー

1
開発者がVS Codeでキーを打つ → extension.ts がキープライブイベントを検出
2
WebSocket で server.js にイベント送信 → 全クライアントへ broadcast（JSON: { type: 'keypress' }）
3
Patinko-home.tsx がイベント受信 → physicsEngine.shootBall() でパチンコ玉を発射
4
Matter.js 物理演算 → へそ入賞検出 → NormalSlot.startSlot() でスロット回転
5
抽選結果により 通常 / リーチ / 大当たり 分岐 → RushMode 起動 または 通常変動継続 → BgmPlayer で演出音楽
+
ユーザーが .pati ファイルを配置 → patidaiLoader が ZIP 解凍 → assetServer が HTTP で React へ動画・音声を配信
